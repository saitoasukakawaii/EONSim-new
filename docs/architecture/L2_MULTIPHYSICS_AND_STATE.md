# L2：多物理场、材料与状态生命周期

状态：采用。适用于物理场组合、时间推进、界面传递和恢复。当前 FSI 主线为单体刚体 → 单体弹性体，详细未知量和装配规范见 [单体 FSI 契约](L2_MONOLITHIC_FSI.md)。

### 一次准备、多次数值更新

```text
读配置/分区 → 建 DoF 与约束 → 建稀疏图/ghost 计划 → 建 solver
每个时间步：
  从 accepted state 生成 trial state
  更新 ghost → 计算本地单元/边界贡献 → 全局装配
  独立场求解对应系统；FSI 用统一残量执行主 Newton
  检查各字段及 ALE 的收敛与必要物理量
  成功：提交所有场及材料历史 → 按输出频率写结果/checkpoint
  失败：保留上一个 accepted state；按 B4 策略有限缩步，次数耗尽则停止
```

不要每次 Newton 迭代重新分区、重新编号或创建 KSP/Mat。首次实现可以每步重算矩阵数值和预条件；观测到开销后，再加 Jacobian 滞后或预条件复用。图结构只在网格拓扑、DoF、约束结构或耦合连接改变时重建；ALE 坐标改变通常只更新几何及矩阵数值。

### 当前主线：独立场到单体 FSI

1. **独立流体和固体：** 固定网格不可压流与静/动态固体分别形成可运行闭环，共用时间、局部残量/切线、状态和装配基础。
2. **刚体与 ALE 准备：** 独立刚体动力学、给定运动的网格扩展及 ALE 流体；给定轨迹不是双向 FSI。
3. **单体刚体 FSI：** 先一个平动自由度；流体、刚体动量和内部 ALE 方程进入同一残量，接口运动学显式消元，由流体力参与决定刚体轨迹。
4. **单体弹性 FSI：** 将刚体小块替换为结构场，先小变形线弹性，再有限变形超弹性。统一主 Newton、跨场导数、线搜索和共同提交；block/Schur 仅是线性求解策略。
5. **分离式及其他多物理扩展：** 主线交付后才安排 Aitken/IQN、热输运、CHT 等。单向物理依赖本身仍可直接顺序计算，但不替代当前单体 FSI 目标。

机械界面统一牵引、位移/速度和参考/当前面积约定。首版共形界面从组合动量残量实现作用反作用，避免重复施加界面力；非匹配网格延期，届时运动学插值与守恒载荷转移分别设计。

单体 FSI 首先建立完整耦合 Jacobian 基线；后续使用近似 Jacobian 时明确标注并检查完整残量。单体方法可以使用近似线性化，但不能把遗漏导数称为一致切线。分块预条件不改变单体方程；分离式子问题各自收敛仍不代表其整体耦合收敛。

后续增加 CHT 时，共形界面优先共享温度 DoF、按区域装配系数；双方外法向下热平衡为 `q_f·n_f + q_s·n_s = 0`。这项扩展不作为当前 FSI 的前置阶段。

## 数据输出、恢复与交付标准

可视化文件服务观察，checkpoint 服务恢复，两者分开。checkpoint 至少包含网格/分区与参考构形标识、时间与步长、已接受流体/固体场、当前网格位移和时间积分必要历史及材料内部变量；刚体版本另存位置、速度及已实现的姿态/角速度。generalized-α 或 0D 模型引入后补齐其状态。不能只保存当前位移就称为可重启。

首版只保证相同分区、相同 rank 数和相容配置重启。各 rank 的数据写完后由协调 rank 写完成标记；读取端只接受完整一代。不同 rank 数重启和在线重分区留到确有需求时实现。

每次运行只保留一份简短摘要：代码版本/dirty 标记、构建模式、PETSc/MPI 版本、输入及分区标识、rank/线程数、时间参数、收敛原因、主要物理量和分阶段耗时。rank 0 汇总，错误按 rank 附必要信息；避免每个 rank 在积分循环刷日志。

一个阶段的“完成”只需满足四件事：**真实算例可运行、所需并行路径可运行、结果有一个可解释的物理判断、Debug/Release 的行为与用途清楚。** 不要求先完善所有 API、测试设施和异常恢复。

## Accepted / trial / intermediate 的严格含义

| 状态 | 可写者 | 生存期与规则 |
|---|---|---|
| accepted | 时间步提交点 | 表示最后一次已收敛时间层；试算过程中只读 |
| trial | 非线性/耦合求解驱动 | 当前候选未知量；可覆盖，不代表物理时间已前进 |
| intermediate | 时间积分映射 | 如 generalized-α 的中间层；由约定的 accepted/trial 及系数生成 |
| material trial | 局部材料更新 | 从 accepted 历史和当前候选场重新评价；不可累积上一轮 Newton 的试算历史 |

残量可能因线搜索、差分 Jv、重试而在同一或不同候选点反复求值。给定同一输入时，残量评价必须可重复；不在评价内部推进塑性、黏弹、主动应力或 0D 边界模型的永久历史。首次实现可以使用明确的独立缓冲区；不需要事务管理框架。

逻辑时序为：`begin_step → evaluate/solve（可重复）→ 所有必要场及耦合收敛 → commit → output`。失败时丢弃 trial 并保持 accepted。实际可能有隐藏状态的材料或外部模型，需提供对应恢复方式；纯代数材料无需虚构历史接口。

跨模块明确增量 `Δx` 是相对“当前 Newton 候选点”的修正，还是相对“上一已接受时间层”的累计增量；默认 Newton 回调使用前者。不能把两者不加说明地传给结构/网格适配器。

## 物理端口与传递契约

接口最少说明：源/目标区域、变量及单位、正方向/外法向、参考或当前构形、时间层、运动学插值还是载荷转移，以及要检查的守恒量。首版用 typed struct 和明确函数参数表达；只有相同机制在第二个耦合中复用时再抽象通用端口。

| 场景 | 传递内容 | 关键约定 |
|---|---|---|
| 流体→热 | 流速、必要材料系数 | 插值位置与取值时间层，反馈有无 |
| CHT | 温度及法向热流 | 两侧外法向相反；共享 DoF 或传递策略择一 |
| FSI | 位移/速度及界面牵引/离散载荷 | 面积度量、力符号、网格速度；检查功或力平衡 |
| 3D↔0D/1D | 流量、压力/平均法向应力、面积 | 流量朝向、压力基准、时间层；压力不自动等于总牵引 |

若运动学传递写为 `u_f=H u_s`，采用一致的离散力定义时，功相容的载荷映射应与 `Hᵀ` 配对，符号按两侧力的约定处理；若传的是应力/牵引密度，还需面积/积分权重。它是设计检查关系，不意味着任意插值矩阵转置都自动满足连续场守恒。

“同进程多场”与“独立子应用耦合”是组织方式；“单向、迭代分区、单体”是数值算法，二者分别选择。首版保持同进程、单一时间步和 communicator；多速率/跨应用只在实际模型要求时加入。FSI 的 ALE 更新必须与本次试算运动一致，移动网格的几何量随之失效；首次接 ALE 时用一个简单均匀流/几何守恒检查确认时间离散一致性。

## B4：实际时间、回滚与缩步

`TimeStepper` 统一流体、固体、ALE、单体 FSI 与刚体 BE 的时间推进。`dt*steps` 定义终止物理时间；缩步后 accepted 步数可以多于配置 steps，`-stop_after` 仍表示 accepted 步数。默认 max_retries=0 保持失败即终止；可在 YAML 根节点设置 `time_control: {max_retries: 6, minimum_dt: 0.0005, reduction: 0.5}`。

只对 `StepRejected`（SNES 未收敛、非法 trial 几何/形变、固体撤载能量检查）缩步。参数、通信和 I/O 失败不重试。每个 accepted 步重置重试次数；失败从相同 accepted 历史重算，包括 tau、BE 链式系数和时变边界。当前策略在成功后保持缩小的步长，不自动增长，也不是误差估计式自适应。

局部装配失败在全 communicator 汇总后才返回数值失败；ALE 在进入求解前同样汇总几何拒绝。固体在临时位移/速度/加速度上检查能量后才提交。流体/FSI 收敛前不改 accepted 状态。

checkpoint v2 同时保存 accepted step、实际 time、next_dt；恢复不再以 step*初始dt 猜测时间。旧 v1 检查点明确拒绝，需重新计算；同 rank/分区限制继续有效。重试次数上限属于运行策略，允许恢复时调整，物理参数仍要求匹配。

`time_retry_verification` 以独立双域 Neo-Hookean FSI、P=20、dt=.04、SNES 最多两次 Newton 触发真实不收敛。缩步轨迹与直接使用最终小步长的参考轨迹对照，检查 1/2 rank、部分保存后的恢复及重试耗尽；不靠测试专用失败开关。
