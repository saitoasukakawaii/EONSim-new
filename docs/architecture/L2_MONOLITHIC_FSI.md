# L2：单体刚体与弹性体 FSI 的实现契约

状态：采用，2026-10-29 更新。P5–P8 小算例、B3 独立共形双域及 B5 导数/求解扩展已有实现；下文区分当前能力与后续扩展。本项目的离散方案不代表上游项目采用同一离散。开发次序见 [路线与工作流程](../development/ROADMAP.md)，通用历史规则见 [多物理场与状态](L2_MULTIPHYSICS_AND_STATE.md)，进一步审查与方案见 [下一阶段详细设计](EONSIM_NEXT_STAGE_DESIGN.md)。

## 目标和首版范围

后续共形 trace 与非一致界面、K/W 映射、力/功传递及嵌套预条件详见 [通用 FEM 规划](GENERAL_FEM_ARCHITECTURE_PLAN.md) §6–7；BDF2/generalized-α 见 §9。实现前保持本文件的 Tet4/BE 约定。坐标匹配不自动意味着不同空间可共享 DoF，人工 ALE 界面残量不作为结构力；共享 DoF 在普通 PC 分区树中只能有一个代数代表。

主线为独立流体、独立固体、**monolithic 刚体 FSI、monolithic 弹性体 FSI**。分离式 Dirichlet–Neumann、Aitken/IQN 等在主线交付后再做。“网格分区”指 MPI 数据分布，与“分离式耦合算法”不同。

第一刚体版本是单个、由流体力参与驱动的运动刚体，先启用一个平动自由度。固定刚壁只是 CFD 边界；预先指定轨迹只是 ALE 准备案例，二者均不记作双向刚体 FSI。6-DoF 是该版本之后按需求扩展的能力，不阻塞弹性体路线。

首版采用 3D Tet4、低 Re 不可压 Newtonian 流体、共形贴体界面、同一步长、无接触、无重网格。刚体做小行程，弹性体先小变形，再有限变形可压缩超弹性。大行程导致网格失效时明确终止该算例，不为首版加入接触/重网格/浸入边界框架。

## 单体的可执行定义

一次时间步有一个组合残量 `R(X; accepted, dt)=0`、一个主 SNES/Newton 循环和一个全局增量。流体、刚体/固体、ALE 内部未知量同时参与本项目的主系统；接口运动学已消元的未知量不必重复保存为独立代数自由度。

首次初始化也使用同一约束映射：参考/当前网格、刚体或固体位置、接口速度和初始历史相容。先选择静止相容初态或平滑加载的小案例，不能由两个独立驱动分别产生相互冲突的接口初值。

- 每次残量评价由同一个 trial 重建几何、网格速度、材料、接口和各残量块。
- 一个全局线搜索/增量更新一致作用于所有自由块；物理场不在内部推进自己的时间步。
- 全部字段及 ALE 方程的缩放残量满足要求后共同提交。
- 首个可信基线使用完整耦合 Jacobian。为调试可暂时使用小问题差分 Jacobian，但必须扰动完整残量并控制成本；不可把遗漏耦合块标为一致 Newton。
- block preconditioner 内部可以依次求解各块，它仍是单体线性系统的求解手段，不等于分离式 FSI。

其他文献也存在对 ALE 导数使用近似的单体方法，因此“单体”与“精确 Jacobian”不是同义词。这里选择先建立完整导数基线，是为了分清实现错误和后续近似优化；近似必须显式标注并与基线对照。[Failer–Richter 的近似 Newton 例子](https://arxiv.org/abs/1904.02401v2)

## 第一版时间与未知量约定

统一使用 backward Euler（BE）。静力固体以位移为未知量；动态固体和 FSI 默认以固体速度为独立未知量，位移由时间关系恢复，避免额外引入一份运动学方程。以下下标 n 表示已接受状态。

```text
固体：d_s = d_s,n + dt * v_s
      a_s = (v_s - v_s,n) / dt
刚体单轴：q = q_n + dt * V
          a_r = (V - V_n) / dt
ALE：x_m = X_m + d_m
     w_m = (d_m - d_m,n) / dt
```

上述选择是 BE 下的方案，不能直接照搬到 generalized-α/BDF2。二阶时间格式在首个单体弹性 FSI 基线完成后再引入，届时同时更新各场、接口和切线链式系数。BE 有数值耗散；当前案例不据此声称二阶精度或精确保能。

用 I 表示未被本质边界或接口运动学消元的流体/ALE 自由 DoF，Γ 表示界面：

| 模式 | 全局独立未知量 X | 从 trial 恢复的量 |
|---|---|---|
| 独立流体 | `[u_f, p_f]` | 时间导数、应力 |
| 独立动态固体 | `[v_s]` | `d_s, a_s` |
| 单轴刚体 FSI | `[u_f,I, p_f, V, d_m,I]` | `q, u_f,Γ, d_m,Γ, w_m` |
| 弹性体 FSI | `[u_f,I, p_f, v_s, d_m,I]` | `d_s, a_s, u_f,Γ, d_m,Γ, w_m` |

表中分组是逻辑块；实际全局编号仍按 rank owned 区间，通过 IS 描述各字段。固体压力只在未来采用混合近不可压缩固体时加入，不给首版虚构压力未知量。

## 界面约束与力的装配

### 共形弹性体：共享运动学，组合动量残量

界面满足 `u_f,Γ = v_s,Γ`、`d_m,Γ = d_s,Γ`。利用现有 DoF 映射消去重复界面速度和网格边界自由度；在同一界面速度测试空间累加流体与结构动量贡献，表达离散作用与反作用。

设 `r_f,Γ` 为**尚未清零/替换 Dirichlet 行**的流体界面动量残量，`TΓ` 将结构速度映射到匹配界面速度，则组合结构动量行为：

```text
R_s = r_s + TΓᵀ r_f,Γ
```

这里约定流体残量为“惯性＋内力－已知外载”；相应流体作用于结构的离散力为 `−TΓᵀ r_f,Γ`。仅加入属于 FSI 界面的贡献。应力积分可用于后处理和检查，但不能再作为第二份载荷重复添加。首版不需要界面 Lagrange multiplier、罚参数或 mortar 系统。

ALE 网格运动是几何扩展方程，其人工“弹性力”不是物理载荷，不能把网格边界反力加入结构动量。

### 刚体：有限维约束，投影为广义力

单轴平动时 `u_f,Γ = B V`，B 是指定方向对应的界面速度映射；`d_m,Γ` 由 q 和初始几何确定。刚体动量行采用：

```text
R_r = m*(V-V_n)/dt + c*V + k*q - F_ext + Bᵀ r_f,Γ
```

其中弹簧/阻尼仅在 case 明确要求时存在，q 相对其平衡位置定义。这是首个可运行的单体流体—刚体系统，不以把弹性模量取极大来模拟刚体。

需要 6-DoF 时再加入平动 V、角速度 ω、质心与姿态 Q，使用 `u_Γ = V + ω×(x_Γ−x_c)`，并明确惯量张量所在坐标系和姿态更新。有限转动不能用位移分量的简单相加替代姿态更新；若映射 B 随姿态变化，`Bᵀr_f,Γ` 的导数还包含 `(δB)ᵀr_f,Γ`。该扩展要独立处理，不能宣称单轴案例已验证六自由度。

## ALE 方程与几何导数

首版在参考流体网格上用系数固定的向量 Laplace 扩展位移；共形界面位移来自当前刚体/固体 trial，固定外边界给定网格位移。网格质量确有需要时再换成伪弹性扩展。内部网格残量 R_m 和未知量 d_m,I 留在主系统中。

流体的 ALE 对流速度使用 `u_f−w_m`；质量项、梯度、积分权重、压力/连续性和稳定化在同一当前几何评价。只替换对流速度并不足以保证离散几何守恒；移动网格时间项必须与几何更新一致，并用一个边界条件相容的均匀流案例确认。

首次实现保留完整 ALE 块最直观。以后若消元内部网格变量，必须传播其对接口运动的灵敏度；“在主 Newton 外单独算一次网格并冻结”不是本项目完整切线基线。

## Jacobian 与预条件

把刚体速度或固体速度统记为 z，约束消元后的 Jacobian 具有下列逻辑结构（具体零块取决于选定方程）：

```text
                 u_I       p          z          d_m,I
R_fluid      [   J_uu     J_up       J_uz         J_um   ]
R_continuity [   J_pu     J_pp       J_pz         J_pm   ]
R_body/solid [   J_zu     J_zp       J_zz         J_zm   ]
R_mesh       [     0        0        J_mz         J_mm   ]
```

采用稳定化等阶流体时 J_pp 不必为零。J_uz/J_pz 包含接口速度约束及时间映射；J_um/J_pm 包含几何、网格速度和稳定化对网格位移的依赖；J_zu/J_zp 来自同一界面动量贡献；J_zz 还包含材料、惯性及接口运动的链式导数。不能只拼接各单场对角矩阵。

先用现有 PETSc 配置中的稀疏 LU 解一个很小的组合系统，隔离装配错误。再转到 GMRES/FGMRES 与块预条件；迭代预条件需要保留有效的流体—结构耦合近似，不能预期简单块对角对所有密度比都有效。默认仍用一个 AIJ＋显式 field IS，MatNest 不是首版前提。

J_op 与 P_mat 分开：完整 Jacobian 用于线性化，P_mat 可舍弃部分耦合或几何项以降成本。刚体小块可用小型稠密解；弹性体则需要真正的分布式结构块求解。刚体小块做得快，不等于弹性 FSI 已有可扩展预条件。[PETSc Jacobian 接口](https://petsc.org/release/manualpages/SNES/SNESSetJacobian/)、[字段分块预条件](https://petsc.org/release/manualpages/PC/PCFIELDSPLIT/)

## 回调与状态边界

名称表示职责，先用具体函数实现，不要求新增继承框架：

```text
evaluate(X, accepted, dt):
  展开当前时间关系与界面运动学
  更新 trial 几何及 ghost；计算当前网格速度
  评价流体/结构或刚体/网格残量
  在统一映射中组合界面动量并装配
  返回组合残量及需要的切线；不提交历史
```

独立流体/固体驱动调用同一套局部 kernel，只是采用不同边界/组合方式。FSI 不在残量回调里调用独立流体或固体的“运行到下一时间步”函数。

刚体全局自由度只有一个 owner；各 rank 的局部界面贡献累加到该 owner。总质量/弹簧等全局项只装配一次。ghost/广播可以复制当前刚体小状态供局部计算，但不能创建多个独立刚体代数未知量或重复累加全局力。弹性 FSI 的界面 DoF 同样保持唯一 owner。

## 最少但必要的证据

首次接入刚体或弹性接口时，用同一个小案例完成：实际双向运动、所有块残量收敛、界面功/力符号合理；新增跨场或几何切线用少量方向的整体 Jv 差分定位。只在新增通信映射时补 1/2 rank 对照，不每次重跑整套案例。

最终“单体 FSI 完成”至少意味着：独立 CFD/结构仍可运行；运动与载荷双向参与同一残量；ALE 与接口依赖进入主求解；共同提交；在小型分布式案例中成立。仅有动画、单场收敛或把两个求解器放在一个 executable 里均不构成这些证据。

## 研究依据与选择边界

Wick 的工作展示了参考域 ALE、统一变分方程及方向导数 Newton 的实现组织；本项目只借鉴这种组织，网格扩展、单元和首版时间格式采用上述较小范围。[Wick, 2011](https://d-nb.info/1195628889/34)

文献中的速度—位移消元和近似 Jacobian 为后续优化提供参考；本项目先使用显式 ALE 块和完整耦合切线，之后再凭证据简化。[Failer–Richter](https://arxiv.org/abs/1904.02401v2)

[既有项目审查](../research/EONSIM_PERIGEE_REVIEW.md) 中 PERIGEE 的网格分段求解是其实现事实，不自动成为本项目的默认算法。


## 历史基线（P5–P8）

随仓库算例使用立方体流体的 x=1 活塞或共形弹性末端块；弹性块通过同一逻辑网格的
x 反射/厚度映射生成真实参考域 [1,1+thickness]，不是任意双网格接口搜索器。
有效编号由 owned 未知量计数和 ghost 主编号交换构造，重复界面未知量直接消元。
流体界面测试残量映射到刚体/结构动量，网格界面测试行丢弃。

P5 的完整流体/ALE 耦合切线使用局部中心差分，含几何、面积和网格速度；
独立流体与线弹性/Neo-Hookean 材料切线为解析。选择前者是为小算例先验证完整跨场导数，
不把它报告为高性能解析 FSI 实现。P8 保留该完整 operator，分块预条件使用 flow、mesh、rigid/structure，
默认 ASM＋局部 ILU；本机多个 SuperLU_DIST 子因子销毁存在 communicator 重复释放问题。
checkpoint 只保存整体已接受 BE 状态，暂限同 rank/同分区恢复。具体命令与验证数据见 README。

## B3：独立共形双域

`fsi.domains` 给出独立 `solid_mesh`、两域体标签、两侧界面标签、压力入口标签及流体/网格/固体的齐次分量约束。入口例为 `cases/fsi/domains/case.yaml`。界面为真正共形三角网格，节点可独立编号和排序，内部单元数/节点数无需相同；不支持非匹配插值。

串行 `read_fsi_domains` 对指定界面按绝对坐标容差做空间桶搜索，检查节点双射、三角面双射、面积相容和相反外法向；只有匹配界面节点合并。联合网格的节点/单元 ID 按输入顺序重新生成，原始源 ID 不作为跨域身份。两域体/边界标签须互不混淆，外边界可不设约束的方向采用零自然条件。流固区域节点关联在预处理时完整建立，分区 v2 增加 `node_cell_tags`，旧分区需要重新 prepare。

联合网格只用于一次离线 METIS 分区；各 rank 在求解时只读自己的分区，不加载任一原始全局网格。全局有效编号消除区域不存在的字段；界面 u、d_m 映射到结构速度，mesh 测试行丢弃，BE 链式系数进入同一个 SNES。结构单元使用独立参考坐标，不再从流体镜像生成。输出分别筛选两域单元，保留共同本地点表供共享节点/owner 对照；未被该域单元使用的点无物理场解释。

`domains_verification` 使用不同内部划分的 48/51 单元两域，验证共同界面位置/速度、动量平衡、1/2 rank、同分区重启、整体 Jv，以及界面错位拒绝。现有镜像小算例入口仍保留作历史回归。


## B5：默认一致 ALE 切线

B5 已将流体/ALE 默认局部中心差分替换为解析几何导数加前向链式传播；`-fsi_fd_tangent` 可显式选择旧参考。体积、形函数梯度、对流网格速度和压力面积都对同一 trial 状态求导，tau 仍按 accepted 速度与本次 dt 冻结。接口消元及 BE 系数继续作用于该完整切线。

`-schur_pc` 保留统一 SNES 与共同提交，只改变线性预条件。`schur_verification` 对独立流体、独立双域 FSI、旧刚体和 Neo-Hookean FSI 做整体直接解与 1/2/4 rank Schur 对照。新切线与差分轨迹、局部方向导数和既有全局 Jv 均验证。

G0B 将上述固定界面映射集中到 `ReducedLayout::slot`：每物理槽返回试探列/本地代表、测试行、重建系数和lifting。
`fsi.cpp` 的场展开与装配共同使用它；mesh界面测试行仍舍弃，结构kernel内部时间导数保持原含义。
三种语义PC树只分组独立代表，界面行不复制；真实验证状态见 [实施记录](../development/FEM_INTEGRATION_VALIDATION.md)。
