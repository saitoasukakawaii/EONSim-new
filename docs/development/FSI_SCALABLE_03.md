# FSI-SCALABLE-03 · 中大型弹性管

基线为 PR #70 的合并提交 `14d36940e`。沿用[冻结协议](FSI_SVFSI_BENCHMARK.md)的物理输入、每四步场输出、逐步历史及零牵引外壁。下列判据先于本轮候选运行记录。

* 内部筛选比较同一物理网格、同一输入的 EONSim 解。A 和 B 采用已完成的直接法轨迹。逐一核对全部区域四面体、节点、共享点与保存场，场和逐步历史沿用绝对差 2e-9。每个 Newton 校正要求原算子残量不超过 max(1e-23, 1e-10 ‖b‖)，并核验接受步及原协议的流量、守恒、界面、压差、环应变和 RCR 指标。直接法参考保留原二进制、日志与输入身份。
* C 首选同方程直接参考。若触及原资源上限，采用独立的物理 Schur 与单体层级配置分别求解，每个校正均核对原方程，并按上述阈值交叉比较全部保存场和历史；其中一组使用 1e-11/1e-24 的独立残量要求。两条路径须各自通过。参考范围仅限已运行窗口。
* 跨代码配对沿用原驱动。内部收据单列已有外部配对状态。本次筛选的时间含诊断，不计入正式性能统计。C 的失败对照没有合格时间分母。
* 首次失败重放固定原二进制、输入、分区、MPI 数、容差与 ASM 参数。PETSc 监视器和矩阵输出仅用于查明首个系统的停滞轨迹。服务器原始目录为 `$HOME/workspace/fsi-scalable-02-runs/C20-fixed`。

## C 首个失败系统

作业 409 用原二进制 `125cfbbab2fb…` 和 C20-fixed 的原分区复现。首步 Newton 迭代 0 发起的第 1 次线性校正，64 rank、924,953 DoF、55,761,870 个矩阵结构非零元。外层为右预条件 FGMRES、未预条件范数、restart 100、经典 Gram–Schmidt、max_it 3000、rtol 1e-10、atol 1e-23。64 个 ASM 子域 overlap 1，本地 PREONLY/ILU(2)。根 KSP 返回 `DIVERGED_ITS`，报告的集体 PC 失败标记为 0。原运行约 124.538 s 后退出。

原运行 `‖b‖₂ = 1.90849368338306e-9`，末次原算子 `‖Ax−b‖₂ = 1.875291563057991e-9`。重放从迭代 499 的 1.875291562555e-9 到迭代 3000 的 1.875291562338e-9。原日志的 mesh、pressure、structure、velocity 块 RMS 分别为 1.466e-18、8.315e-13、6.063e-13、3.279e-12，各块约束行最大残量均为零。该对照使用裸 ASM，未走 RCR bulk PC，也没有后续接受步或层级刷新。日志证实停滞；粗层、物理附加质量或压力零空间均未被确认为根因。

原件在 `$HOME/workspace/fsi-scalable-03-runs/C-first-64`，含 PETSc 矩阵、右端和 64 个分区输入的哈希。`C-layout` 有 64 组 owner 行和 owned/ghost 物理槽映射，沿用生产布局的入口约束消元和界面别名。矩阵原样保留 RCR 行 924952（从零计数），首个系统的端口右端为零，对角元 8.1140351e-9，初始电容压力为零。现场保留原 case、边界标签和分区。复核未对常压力模态施加投影。[哈希与原始日志索引](../research/data/fsi-scalable-03/log-index.json)

B 的首个系统有 5,845,834 个结构非零元，限值为 5.52652e-19。ASM、physics、暂定插值、压力自动粗化的末次真残量分别为 5.2614e-9、8.1358e-18、3.6714e-9、3.6227e-9。两种 MG 均使用 `-rcr_bulk_monolithic_mg_`，端口报告显示一次重建、一次成功 response，运行进入 1,500 次外迭代。physics 的速度和结构子 KSP 达到各自预算。为区分子块近似与数值误差，作业 415 复用分布式 SuperLU_DIST 作 FGMRES 右预条件器，restart 2、max_it 12，原精度不变，残量仍为 8.1228e-18。作业 416 保存该配置的矩阵、右端和末次迭代向量，诊断额外 PETSc 选项为 `-ksp_monitor -ksp_view_mat binary:operator.petsc -ksp_view_rhs binary:rhs.petsc -ksp_view_solution binary:iterate.petsc`。独立 64 位尾数乘加测得 6.072707e-18，其中结构块 6.072693e-18。该结果限定于保存的向量，尚无所有 FP64 解的残量下界。

B 原版使用 FS GMRES 和 MS CG，原生记录在第 3 步第 7 次校正分别为 9020、2000 次内迭代，780 s 超时。作业 417 仅改变 FS 的原生预条件器为行列缩放，同一物理输入与资源，首步 FS/MS 均出现 NaN，RCR 积分中止。B/C 没有外部速度比。

A 两个长窗双方各预热一次，交错三对正式作业。32 步 ASM/svFSI 中位数为 1.11585/12.62141 s（11.311 倍）；100 步为 3.02171/38.82836 s（12.850 倍）。前处理分别为 0.02051/0.01053 s。独立诊断的推进循环时间分别为 0.92676/12.37114 s 和 2.86416/38.36614 s。ASM 的 64/200 次校正均通过，最大残量/允许值 0.984783；双方诊断与各自正式运行的全部保存场最大差均为零。B/C 的失败时间均排除在加速比之外。[逐次收据](../research/data/fsi-scalable-03/validation.json)
