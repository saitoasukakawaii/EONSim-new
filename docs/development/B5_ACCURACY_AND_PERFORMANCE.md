## 独立双域 FSI CPU 测量

每项计算 3 个 dt=0.02 步。direct/Schur 默认使用解析几何与前向链式切线；fd 使用原中心差分切线和整体直接解。
solve 包含显式预条件准备及 SNES；assembly 包含这段时间内残量/切线装配；ghost 是其子集。wall 还包含 MPI 启动、读入和输出。
RSS 是作业中各 rank 的进程峰值；sum 是各进程峰值之和，不代表同一时刻总内存。每配置单次测量，不能据此宣称并行加速或大规模可扩展。

全部 FSI 对照的最终界面位移差小于 2e-9；完整节点场与力平衡的 1/2/4 rank 对照见 schur_verification。

测量日期：2026-10-29；GCC 13.3、Release、PETSc 3.23.2、OpenMPI 4.1.6。原始日志、VTU 和 summary.json 可由上面的脚本复现。

速度 L2 的后两层观测阶约 1.84，压力约 0.98；最细通道压降仍有约 15% 偏差，需要继续空间加密。FSI 相邻时间步位移差的最后两个比值约 1.82/1.92，趋近 BE 的一阶行为；这些时间误差仍针对固定空间网格。

该批 CPU 测量中，解析几何/前向链式切线与中心差分的装配时间接近，没有证据宣称显著切线加速。Schur 的初始显式准备多做一次装配，因此其 assembly 时间不能与直接解简单解释为单次 kernel 成本。2299 DoF 单 rank Schur 的峰值 RSS 约 257 MiB，整体直接解约 354 MiB；迭代数随网格增加，尚未实现网格无关收敛。
