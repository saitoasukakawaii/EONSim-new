## 周期检测

`scripts/study_fsi_periodic.py` 在同一物理 checkpoint 上逐周期续算。默认每周期20个完整场快照，比较流体速度/压力/ALE位移、固体速度/位移，以及面积平均壁位移、流体体积和出口流量。场范数为参考体积加权的节点 lumped L2 范数；不是精确连续 L2 积分，也不是单个探针值。具体为 `sqrt(sum(w_i*|e_i|^2)/sum(w_i))`，即按参考体积归一化的离散RMS；每个Tet4给四个节点各分配其参考体积的四分之一。周期判据取各相位此量的最大值，时空研究则再取相位RMS。

固定归一化尺度：速度0.01、压力0.1、位移及体积变化1e-4（合成通道单位）。不能用较大平均值作为分母掩盖振荡漂移。相邻周期的同相位场差取相位最大值；所有场和观测量连续三个周期小于指定阈值才通过。默认阈值1e-3。标量另报告均值漂移。

相位按物理时间对齐。非对齐快照允许时间线性插值，但不外推，跨度大于T/16的插值区间拒绝；研究必须另检查相位采样误差。当前研究驱动使用固定步长，周期须含整数步且能均分指定快照数。检测器能处理非均匀时间点，不代表驱动已经提供通用自适应周期控制。

```bash
python scripts/study_fsi_periodic.py --executable build/cloud-3.23.7-release/eonsim \
  --mpiexec <prefix>/bin/mpiexec --work build/periodic-n4 --n 4 \
  --ranks 2 --dt .001 --automatic-tau --cycles 160
```

达到周期上限而未通过时返回失败，并保存未收敛 receipt；不能把程序结束视为周期稳态。首次运行要求空目录。恢复增加 `--resume` 并保留 n、rank、dt、格式、稳定化、尺度、阈值及采样数；允许增加周期上限。`--minimum-cycles` 可要求追加周期以估计剩余瞬态。

`fsi.checkpoint_interval` 控制接受步保存间隔，默认1，必须为正整数。无论间隔如何，成功到达请求停止点或最终步时都保存；失败/拒绝步不保存。研究驱动设置为每个周期的步数，避免对每个中间步写一代文件；不改变物理状态和恢复签名。

`study-definition.json` 固定算例参数、网格哈希、可执行文件哈希，以及检测/生成器/运行辅助脚本指纹。修改判据或网格生成代码后不能仅凭同一个二进制复用旧计数或缓存。恢复先验证定义及接受历史连续性；receipt 指向完整周期的 checkpoint generation，不把后来失败尝试的部分进度作为完成周期。再次执行该周期前保留失败尝试文件。周期receipt采用临时文件替换发布。

## 质量预算和几何

`fsi_tet_mass_observation` 从当前Tet4分别积分体散度与四个面通量；生产路径仍由边界标签选择进出口/壁面，再做MPI标量归约。三轴伸缩加平移的解析四面体验证体积为时间三次多项式，表面通量与解析体积导数一致；纯平移总通量为零。这些检查不等于自由流保持或局部强守恒证明。

`volume_budget` 用实际接受时间对端点净流量做梯形积分，并与真实端点体积变化比较。缺失/重复/非有限历史拒绝。该积分是后处理质量预算，不是替代BE/BDF2/alpha的算法导数。

## 时空研究

`study_fsi_time_accuracy.py` 在固定网格、固定tau下，对第二个完整驱动周期比较三个时间格式和更细参考。它验证瞬态时间阶，不声明该时段已周期稳态。粗步长失败证据必须保留；进入渐近区时继续加密，不放宽原速度/位移阶门槛（BE 0.85，BDF2/alpha 1.7）。压力阶单独报告。参考再加密差须小于候选误差的10%。

`analyze_fsi_space.py` 在参考构形上用真实粗网格Tet4做P1插值，比较n=2/4/8的完整周期；不使用相同节点编号冒充同一空间位置。报告各场差和压降波形；该脚本的差异递减检查本身不足以完成任务，仍需时间污染、剩余瞬态及相位采样误差验证。

## 继续计算与采样误差

`study_fsi_transient_tail.py` 从已收敛周期的指定generation再计算三个等长周期块。它报告完整场块间差、实测收缩率和条件性几何尾项估计；非衰减或q≥0.8拒绝该估计。该结果依赖衰减继续，不是严格渐近误差界。

`study_fsi_phase_sampling.py` 从同一状态继续两个周期，输出每周期100个真实场快照，在第二周期比较20相位线性插值与100相位实际场。完整包络包括周期起点和终点，不靠外推补齐。`analyze_fsi_space.error_budget` 要求每个场的时间、瞬态和采样估计分别严格小于末档空间差10%，缺字段/非有限估计直接拒绝。


最终预算入口 `analyze_fsi_error_budget.py` 接收三网格原步长、三网格半步长，以及这六个周期状态各自的追加周期和密集采样结果。正式场差采用实际100相位数据；通过50/100相位的场差统计变化检查相位积分稳定性。20相位波形重建误差仍单独报告，不把它混同于100相位场差积分误差。时间和剩余瞬态的原10%门槛不变；时间估计另计入两端状态的经验瞬态不确定量。

误差估计与源状态通过checkpoint generation、完整checkpoint文件集合及SHA、网格SHA、研究定义绑定。
恢复到不同目录不需要改写旧receipt的绝对来源路径；同名目录下内容改变也会拒绝复用。
这只保证离线证据归属，不替代不同构建继续计算前的完整周期重放相容性检查。

审查发现仅检查接受历史连续性不足以拒绝截断的最后几行。恢复路径现在同时核对历史终点；时间矩阵同时核对全部接受步数、最终物理时间和20个确切相位。对原始数据重新分析已通过；故意截断恢复历史的负例回归在后续检查中执行。
