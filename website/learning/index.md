# 学习路径

本网站按知识依赖组织内容。建议先学习数学和离散基础，再进入具体物理求解器，最后学习 HPC 并行和软件工程。

| 路径 | 适合读者 | 学习成果 |
|---|---|---|
| [CFD 求解器](/learning/cfd) | 流体力学、计算力学学生 | 理解不可压缩流动方程及其数值求解 |
| [有限元与固体力学](/learning/fem) | 有限元初学者和结构计算研究者 | 从弱形式走到单元残量与切线 |
| [HPC 与并行计算](/learning/hpc) | 科学计算软件开发者 | 理解分区、DOF、MPI 通信和 PETSc |

## 建议的先修知识

- 多元微积分、线性代数和常微分方程；
- 张量记号、连续介质力学基础；
- C++ 基础和 Linux 命令行；
- 数值分析中的误差、稳定性和收敛概念。

每篇专题会标注先修知识、核心公式、代码入口、验证方法和练习。
