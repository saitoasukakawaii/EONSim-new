# 单体 FSI 的时变载荷与接受步历史

面向维护瞬态有限元驱动和 MPI 输出的开发者。本文仅讨论现有三维共形弹性端块与单轴刚体，不讨论非匹配界面或生产扩展。

## 设计依据：评价时间也是离散方程的一部分

**理论/项目离散约定**：压力给定为时间函数，但当前受压面的面积、法向依赖 trial 几何。
设压力为 `s(t)*(p0+A*sin(2*pi*t/T))`，启动包络使用五次多项式
`s(x)=10*x^3-15*x^4+6*x^5`，`x=clamp(t/tr,0,1)`。
由多项式直接求导可得启动两端一、二阶导数为零，与外侧常数段相容。

BE/BDF2 自然载荷取终点值；本项目 generalized-alpha 使用共同阶段
`t_n+alpha_f*dt`，初始 BE 步仍取终点。若仅用终点压力替代阶段压力，
残量虽可能收敛，求解的却是不同的时间离散。压力与 trial 无关，所以它的状态导数为零；
压力乘面积法向的几何导数不能丢弃。
依据为仓库 [FSI 契约](../../docs/architecture/L2_MONOLITHIC_FSI.md) 与
[时间积分契约](../../docs/development/TIME_INTEGRATION.md)，不是新提出的普适 FSI 算法。

## 实现：候选步取载荷，接受后写历史

**实现证据**：源码提交 `a6c6761084f2003c72593107c6aa5cbc351d75bb` 的
`src/physics/fsi.cpp` 在每次候选步计算压力，注入原局部单元数据。
同一份残量用于 Newton 和界面力检查；拒绝步重算压力，不修改 accepted 历史。
波形参数纳入 checkpoint 签名，输出间隔不属于物理签名。

字段提取每次从参考网格重新建立输出坐标，避免把上一步位移重复叠加。
CSV 把终点运动与评价时间的载荷、力、功率分开命名。
弹性体运动量是界面节点算术平均，不是面积平均或点探针。

所有 rank 写完片文件后再发布索引，局部异常在进入下一 collective 前统一传播。
这避免失败 rank 抛异常而其他 rank 卡在 barrier。
恢复使用独立历史前缀；历史不是 checkpoint，也不是跨文件断电事务。

## 验证与排查

**验证证据**：[本地命令与原始精简结果](../../docs/research/data/fsi-pressure-2026-11-03/README.md)。
PETSc 3.23.7 Debug/Release：1/2 rank、三种时间格式、启动/周期段恢复、真实缩步重放、
快照几何、最后快照与最终场一致，以及 rank-local 写入失败均通过。
固定网格和 tau 的时间精度检查得到 BE 约一阶，BDF2 与 alpha 约二阶。

首次 BE 粗步速度阶数只有 0.745；细化后达到 0.942/0.971。
这说明载荷变化时间尺度必须被时间网格解析，不能因为粗步未进入渐近区而调低验收标准。
参考仍是同一空间离散的细步解，因此该实验不证明空间误差或实验真实性。

另一个测试错误来自双域 MPI 比较器：节点 owner 不一定拥有该输出域的相邻单元。
仅取 owned 且在本地输出域使用的节点会漏项；应按域单元使用节点收集，再按稳定网格 ID 比较。
所有最初失败及修正都保留在验收记录，不混入通过数。

## 限制与审核问题

**性能证据**：未测量。小规模通过不支持强扩展结论。
只保证相同 rank/分区重启；没有非匹配接口、重网格、逐标签波形或历史自动拼接。
草稿未发布。审核时重点检查压力符号沿用关系、阶段时间命名、输出失败后的 checkpoint 语义。
进一步练习：保持固定空间算子，把载荷周期减半并重新观察达到渐近阶数所需的时间步长。
