# 弹性管首个 Newton 校正与粗层通信域的独立核验

## 物理问题和误差尺度

四分之一弹性直管从静止启动，入口周期为 1 s，时间步为 1/32 s。端口采用 RCR，外壁零牵引。每个 Newton 校正验证原装配算子。在本协议下，令右端为 (b)，PETSc 返回的校正为 (x)，验收要求 `norm(A*x-b) <= max(1e-23, 1e-10*norm(b))`。对不同网格，须用实际右端范数算出本次的绝对限值。

## 首次失败的原始系统

C 的 924,953 行矩阵含 55,761,870 个结构非零元。首步第一校正的右端范数为 1.90849e-9。64 MPI 的 ASM(1)/ILU(2) 在第 499 次外迭代时已停滞在 1.87529e-9，直至 3000 次迭代耗尽预算。重放保存了 PETSc 二进制矩阵和右端。该例没有指向某个多重网格粗层的运行证据。

B 有 101,085 个自由度。分布式直接法完成了全部 20 步，独立重放发现首个校正超过原算子限值。用同一分解作 FGMRES 右预条件并在短重启后重新构造残量，也未通过。将保存的双精度矩阵、右端与末次迭代向量提升到 64 位有效尾数重新乘加，残量为 6.07e-18，目标为 5.53e-19。这个试验证明保存的向量未达标；要判断其他表示或解法能否满足精度，仍须独立求解和复核。

## 通信域和端到端时间

另取 108,379 DoF 的合成五步问题，在同一双路 EPYC 7763 的 128 个物理核上纯 MPI 运行。合成问题的载荷、时间步和物理窗口与上述管道不同。最粗矩阵有 1,488 行。两组均使用 owner 本地 Braess 通路，外迭代数均为 1,724。在最粗层事件中，原配置有 32 个 rank 各记录 197,760 次归约，其余 96 个 rank 各记录 1,724 次。改为每个粗层进程预算 1,024 行后，有 2 个 rank 各记录 62,398 次归约，其余 126 个 rank 各记录 1,724 次。

作业计时包括启动、层级设置、通信、迭代和场输出。双方各一次预热，再交错测量三次，关掉额外求解器报告。作业中位数从 44.507 s 降至 35.222 s；新配置的最慢样本为 42.156 s。逐层事件含嵌套，端到端时间直接取作业计时器。[协议、全部样本和现场复跑入口](../../docs/development/FSI_SCALABLE_03.md)

## 审阅问题

复核 B 结构块的可达误差时，应保存每次候选实际返回的校正、字段行映射及端口行。验证其他网格的粗层行预算时，须重测合格物理窗口和完整作业的时间。本次合成比较单独支持该网格和资源布局。

## 真实管的四个粗求解器

对每个粗层读取全局行数、各 rank 的本地行数和实际 KSP 通信域，可以区分矩阵存储分布与迭代归约的参与进程。B20 的 physics 分裂预条件器中，速度、压力、结构和网格的 GAMG 最粗算子各为 42、12、39、10 行，32 个 rank 均进入 GMRES，32 个 rank 的行分布为 rank 0 持有全部行，其他 rank 持有零行。改用单 rank 的 GMRES/Jacobi 后，两个配置都核验实际子树、同一个独立 LU、全部保存场和 20 步历史。每侧一次预热，三对交错样本的中位耗时为 53.264 s 和 37.275 s，二者的 Newton/KSP 中位数同为 40/2360。复现实验可从已归档 B20 树逐步核对低层 KSP 的容差、收敛原因和参与 rank 数。[第五阶段实验与复跑](../../docs/development/FSI_SCALABLE_05.md#固定精度的真实管-gamg-粗层通信)

## 同一真实管上的两种通信测量

在 A20 的四个单线程 MPI 进程上，physics 子块的 GAMG 粗矩阵只有 8、5、8、18 行，均由 rank 0 持有。各粗层 Krylov 缩至一个 rank，将同精度中位时间从 2.321 s 降到 1.806 s。在同一网格切换为 RCR 的整体 pressure-MG 时，实际层级有五层。对 Braess-Sarazin 平滑器的 owner 本地读写做同配置消融，开启后中位时间从 6.334 s 降到 2.974 s。每次测量都完成全部 20 步，并与相同的独立直接参考核验。读者可以在每步的 `root/rcr_bulk` 统计中复查平滑应用及压力 Schur 调用，再比较各自三次正式样本。两组降幅的基线不同，选择当前最快配置须看相同物理预算下的绝对作业时间。[原始数据与复跑](../../docs/development/FSI_SCALABLE_05.md#a20-的两种通信比较)
