# 用 Womersley 解检验刚性圆管的振荡流量

给固定圆管两端施加正弦压差，流量的峰值会落在压差峰值之后。对有限元流体开发者而言，
这个相位差和流量幅值提供了两个可独立核验的量。本例再用第二套求解器复算同一张网格，
并测量流量达到误差目标时端面计算压力与施加值的差距。

## 圆管参考解

取轴向坐标 x、截面半径 r，管长 L、半径 R、密度 ρ 和动力黏度 μ 均为常数。
充分发展、无滑移、不可压缩的牛顿流体在刚性圆管内满足

\[
\rho\,\partial_t u_x=\Delta p(t)/L+
\mu\,r^{-1}\partial_r(r\partial_r u_x),\qquad u_x(R,t)=0 .
\]

令入口压力为 Δp sin(ωt)，出口为零。用 `Im(û exp(iωt))` 表示实速度，定义
`α=R sqrt(ωρ/μ)` 和 `z²=−iα²`。径向解与截面积分给出

\[
\widehat u(r)=\frac{\Delta p}{i\omega\rho L}
 \left(1-\frac{J_0(zr/R)}{J_0(z)}\right),\qquad
\widehat Q=\frac{\pi R^2\Delta p}{i\omega\rho L}
 \left(1-\frac{2J_1(z)}{zJ_0(z)}\right).
\]

算例取 R=1 m、L=2 m、ρ=1 kg/m³、μ=1 Pa·s、Δp=0.02 Pa、ω=4 rad/s，因此 α=2。
圆管流量幅值为 0.00323951534 m³/s，相位为 −33.26157°。本文只在这个 α 上计算
贝塞尔幂级数，另用径向数值积分核对流量系数。[Womersley, 1955, pp. 553–563](https://doi.org/10.1113/jphysiol.1955.sp005276)
· [DLMF 10.2.2](https://dlmf.nist.gov/10.2.E2)

## 让两端的条件与解析解一致

采用对称黏性应力时，充分发展解在端面上仍有由径向速度梯度产生的切向牵引。
在两端只给法向应力 −pn，并约束两个横向速度分量，解析解便满足这些条件。
管壁的三个速度分量均为零。EONSim 从零速度出发，使用稳定化 P1/P1 四面体单元、
BDF2 和默认随单元与时间步变化的 SUPG/PSPG 系数。非线性求解容差为绝对 1e−13、
相对 1e−11，线性子问题采用 SuperLU_DIST。阶段载荷与接受步末的观测值分别取时。
[输入与实现说明](../../docs/development/WOMERSLEY_FLOW.md)

两端面积分都采用外法向，因此同向流量为 `(Qout−Qin)/2`。对均匀采样的完整末周期，
用正弦和余弦投影得到复数基波。相对幅值误差比较两个模，
相位误差取复数商的辐角。波形误差按解析波形的离散 RMS 归一化。独立比较
两个相邻周期的同相位样本，避免把尚存启动瞬态的单周期拟合当作周期解。
[分析实现](../../scripts/study_womersley.py)

## 实测

| 量 | 48 个周向扇区、8 个径向层、12 个轴向段，每周期 64 步 |
|---|---:|
| 末周期端面流量幅值误差 | 1.5047% |
| 流量相位误差 | 0.2858° |
| 整周期波形相对 RMS 误差 | 1.5864% |
| 相邻周期最大变化 / 解析流量幅值 | 0.00487% |
| 计算端面压差幅值 | 0.0184844 Pa |

正压力峰值时，入口、中截面、出口的面积平均压力分别为 0.0192128、0.0100203、
0.0007367 Pa，解析值为 0.02、0.01、0 Pa。端面压差幅值比驱动幅值低 7.58%。
对同一 VTU 做体积分，压力 RMS 误差仅为施加压差幅值的 1.05%。
端面是二维积分，体均方误差按各单元体积加权，两项观测对端部偏差的灵敏度不同。
速度相对 L² 误差为 1.19%，元素散度 RMS 为 6.70e−5 s⁻¹。
[逐截面数据和积分定义](../../docs/research/data/womersley-2026-11-20/README.md)

将相同坐标、Tet4 连接、端面条件和正弦系数导出至 svFSI 2022.09.26，使用同样的
广义 α 谱半径零和时间步。两套程序在每一步使用各自的空间稳定化和线性求解器。
以圆管解析流量幅值归一化，粗网格的复数流量差为 8.78%，超过预设的 5%。
上述 25,920 个四面体网格上该差值为 2.04%。核验了外部求解器每个时间步的
非线性残量，并从两个程序的场文件独立计算了终点差异。
[原始测量与波形](../../docs/research/data/womersley-2026-11-20/README.md)

## 复核与适用范围

固定 48 扇区，细化径向和轴向后，流量幅值误差从 2.537% 降至 1.505% 再到 0.755%。
时间方向上，默认稳定化系数也会随步长改变。每周期由 32 步加密到 256 步时，
末相位的体积加权平均系数从 0.00357 降到 0.00174。仅改变步长时得到的复流量变化
同时包含这项效应。另行固定系数为 0.003 后，每周期 16、32、64 和 128 步的两组观测阶为 1.96 和 1.99。

复算只需解开归档并运行 `replay.py`。外部二进制 VTU 场读取另需 Python VTK。
压力迹的精度需要单独设定目标。弹性管有另一项静压压力–面积对照。脉动顺应性与
多节点性能仍待验证。稿件待审。[静压管壁研究](https://github.com/saitoasukakawaii/EONSim-new/pull/42) ·
